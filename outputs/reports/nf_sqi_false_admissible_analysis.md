# Task 3: False-Admissible Feedback Analysis

The SMR-only gate (Gate A) has a false-admissible rate of **43.2%** (windows that pass SMR criteria but contain high broadband/transient noise).

Adding high-beta inhibition (Gate B) blocks **21.5%** of these false-admissible windows.

The full NF-SQI (Gate C) guarantees 0% false admissibility under these definitions, retaining a clean yield of **9.0%** of the total task time.

**Conclusion**: High-beta inhibition acts as a functional safeguard, intercepting a significant fraction of false-admissible states that would otherwise be erroneously rewarded.
