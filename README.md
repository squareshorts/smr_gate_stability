# SMR NF-SQI Reviewer Reproducibility Package

This repository contains the analysis code and derived outputs for the SMR neurofeedback NF-SQI manuscript revision. It is scoped to reviewer reproducibility: preprocessing/spectral feature extraction, virtual gate construction, threshold sensitivity, leakage-controlled modeling, companion-dataset replication, and denominator audits.

Manuscript files are not part of this analysis package.

## Environment

Create the analysis environment with either file:

```bash
conda env create -f environment.yml
conda activate smr-cn-revision
```

or:

```bash
python -m pip install -r requirements.txt
```

## Data

Raw OpenNeuro data are expected under `data/raw/openneuro/` and are intentionally ignored by Git. The replication inventory uses OpenNeuro manifest files under `data/manifests/` and can download the first/last-session subset used by the companion analyses when local EDFs are missing.

Analyzed datasets:

- `ds004447`: primary NF-SQI analysis.
- `ds004444` and `ds004446`: companion replication datasets.
- `ds004448`: inventoried and skipped when no safe rest/task-compatible path is available.

## Reproduce

Run the full reviewer replication pipeline:

```bash
python analysis_replication/run_full_replication.py
python analysis_replication/finish_replication.py
```

On Windows, the same entry point is:

```bat
run_all_main_analyses.bat
```

Primary ds004447 scripts are in `empirical/`:

- `nf_sqi_t1_features.py`: feature extraction from EDF windows.
- `nf_sqi_t2_t3_gates_and_admissibility.py`: threshold fitting and Gate A/B/C labels.
- `nf_sqi_overlap_decomposition.py`: candidate-window contamination decomposition.
- `nf_sqi_t4_t5_modeling.py`: leakage-controlled model comparisons.
- `nf_sqi_t6_robustness.py`: threshold and baseline sensitivity checks.

Companion and reviewer-audit scripts are in `analysis_replication/`.

## Key Outputs

- `outputs/tables/nf_sqi_*.csv`: primary ds004447 summary tables.
- `outputs/figures/nf_sqi_*.pdf`: primary manuscript figures.
- `outputs/replication_tables/primary_replication_summary.csv`: cross-dataset summary.
- `outputs/replication_tables/bootstrap_ci_by_dataset.csv`: bootstrap confidence intervals.
- `outputs/replication_tables/reviewer_denominator_table.csv`: reviewer denominator table.
- `outputs/replication_logs/leakage_control_report.md`: leakage-control audit.
- `outputs/replication_summary/methods_parameter_report.md`: compact methods-parameter report.
- `outputs/replication_summary/final_replication_report.md`: compact replication report.
- `outputs/replication_figures/*.pdf`: compact replication figures.

Large window-level intermediates are regenerated by the scripts and ignored:

- `outputs/tables/nf_sqi_window_features.csv`
- `outputs/tables/nf_sqi_task_labeled_windows.csv`
- `outputs/replication_tables/*_window_features.csv`
- `outputs/replication_tables/*_task_labeled_windows.csv`

## Reproducibility Notes

All retained scripts resolve the repository root from their own file location rather than from a local absolute path. Model validation and bootstrap summaries are grouped by subject; threshold fitting is done within subject/session rest baselines, with task-baseline thresholds limited to sensitivity analyses.
