# Baseline gate stability study

Numerical comparative engineering study of six prespecified EEG quality monitors across calibration stability, session transport, operational availability, downstream information cost, and runtime/software behavior.

The frozen plan and monitor definitions are under `results/baseline_gate_stability/`. Session-level computations are checkpointed; large machine-local checkpoints are intentionally ignored and represented by manifests and validation tables.

No independent artifact ground truth is claimed. The manuscript and `results/final/` are protected and outside this study's write scope.
