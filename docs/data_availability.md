# Data Availability

This study relies on the following open-access datasets hosted on OpenNeuro. To run the analysis scripts, the raw EDFs must be downloaded and placed within the `data/raw/openneuro/` directory structure as indicated in the configuration.

- **ds004447** (Primary Dataset):
  - DOI: [10.18112/openneuro.ds004447.v1.0.1](https://doi.org/10.18112/openneuro.ds004447.v1.0.1)
  
- **ds004444** (Companion Replication Dataset):
  - DOI: [10.18112/openneuro.ds004444.v1.0.1](https://doi.org/10.18112/openneuro.ds004444.v1.0.1)
  
- **ds004446** (Companion Replication Dataset):
  - DOI: [10.18112/openneuro.ds004446.v1.0.1](https://doi.org/10.18112/openneuro.ds004446.v1.0.1)
