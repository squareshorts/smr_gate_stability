# Validation scope report

Accurate framing of what the empirical validation shows:

- It is a **parameter-free composition prediction**: single-criterion reproducibility
  probabilities predict the reproducibility of their higher-order conjunctions.
- It is **not prospective task-performance forecasting**: it does not predict future
  behavioural or decoding outcomes.
- It is **not independent artifact-ground-truth validation**: there is no external label of
  'true bad window'; the target is between-replicate accepted-set agreement.
- The prediction uses held-out single-criterion decision probabilities (legitimate: the
  scientific question is whether composition of single criteria predicts the higher-order
  gate). It does not use the observed higher-order gate Jaccard (confirmed by blinding).
- Positive criterion dependence makes the independence prediction slightly conservative;
  the optional dev-fit correction reduces error but is secondary.
